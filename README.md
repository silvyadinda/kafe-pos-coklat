# Sistem Kasir & Pemesanan Kafe Modern

Aplikasi Kafe POS tema cokelat menggunakan PHP Native (kompatibel PHP 5.6.40) dan MySQL/MariaDB.

## Instalasi XAMPP
1. Salin folder project ke `C:\xampp\htdocs\kafe_pos`.
2. Jalankan Apache dan MySQL.
3. Import `database/kafe_pos.sql` melalui phpMyAdmin.
4. Buka `http://localhost/kafe_pos/`.

## Fitur
- Login dengan peran Admin/Kasir.
- Dashboard omzet, pesanan, menu terlaris, dan stok rendah.
- Pengelolaan kategori, menu, harga, dan stok.
- Transaksi Dine-In/Takeaway, pajak, diskon, dan metode pembayaran.
- Cetak struk, laporan, dan ekspor CSV.

## Catatan keamanan
Akun demo yang ada di kode hanya untuk pengujian lokal. Ganti kredensial sebelum penggunaan nyata. Jangan masukkan data pelanggan atau kredensial rahasia ke repository Public.
